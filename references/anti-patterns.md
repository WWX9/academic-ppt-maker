# Academic PPT Anti-Patterns

Block these patterns when drafting, reviewing, or imitating reference decks.

## Logic Problems

- Open with a broad field lecture instead of a specific problem tension.
- Spend many slides on background without naming the research gap.
- Introduce several methods before the audience knows the main question.
- Show many results without saying what each result is meant to prove.
- End with generic slogans like `取得了较好效果`, `未来继续研究`, or `谢谢聆听` without a real conclusion sentence.

## Structure Problems

- Repeat full agenda or目录 slides multiple times in a short talk.
- Use section titles that do not advance the story, such as five consecutive slides all called `研究方法`.
- Put background, related work, and motivation in separate long sections when one tighter chain would do.
- Place data/setup too early or too late so the audience cannot interpret the method or trust the results.

## Method Problems

- Dump equations or module names without explaining their role in the pipeline.
- Present method components in implementation order when the audience needs causal order.
- Keep backup-level technical detail in the main talk.

## Result Problems

- Mix benchmarking, case studies, ablations, and error analysis on one crowded slide.
- Show figures first and force the audience to guess the claim.
- Use result titles that only describe content, not the conclusion of the content.

## Conclusion Problems

- Repeat the method name instead of the scientific answer.
- Claim success without citing the strongest supporting result.
- Add a long future-work list that weakens the take-home message.

## Distillation Problems

- Copy the visual shell of a reference PPT without copying its narrative discipline.
- Learn from decks that are beautiful but logically loose.
- Merge styles from too many reference decks and lose a stable report structure.
