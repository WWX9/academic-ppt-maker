# Visual Priors

Use this file when the user names specific presenters, schools, or labs whose decks should influence the **appearance** of the final PPT.

Important:

- A visual prior is not automatically a logic prior.
- First choose the narrative skeleton from `logic-rules.md` and `chengdu-review.md`.
- Then borrow color, framing, typography, panel structure, rhythm, and figure treatment from these references.

## Two-Track Reference Strategy

When the user provides or names references, classify each one:

- `logic gold`: copy story order, title-chain discipline, method-result closure
- `appearance gold`: copy visual rhythm, palette, typography, image/card/chart framing

Recommended default pairing for this corpus:

- Logic gold: `报告-杜思齐.pptx`, `面向色觉异常人群的无障碍地图研究进展.pptx`, `信息地理学大会2025_蔡建南.pptx`, `信息地理学大会 刘宝举.pptx`
- Appearance gold: `2025年成都会议-周亮.pptx`, selected PKU decks, selected WHU decks, selected Tsinghua-linked decks

## Style Translation Rules

When converting a preferred visual prior into a new deck:

- copy layout temperament, not literal slide cloning
- keep conference-talk pacing even if the source deck was a defense deck
- keep title-chain clarity even if the source deck uses generic section labels
- preserve the user's topic and evidence hierarchy over the reference deck's original story

If logic and appearance priors conflict, logic wins.
